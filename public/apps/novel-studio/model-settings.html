状态说明

这里仅检查当前运行版本是否读取到配置，不验证密钥、额度、模型权限或调用质量，也不会发起模型请求。

由你输入密钥

本站不会在这个页面接收或保存密钥。请按以下步骤在 Sites 原生设置中操作。

  1. 打开站点管理在 ChatGPT 的 Sites 中找到「丁康的工作空间」，进入该站点的 Settings（设置）→ Environment variables（环境变量）。
  2. 添加密钥新建变量，名称填写 NOVEL_OPENAI_API_KEY，值由你自己输入；启用 Secret 后保存。不要把密钥粘贴到聊天里。
  3. 检查模型名称站点需要 NOVEL_OPENAI_MODEL，其值应是你的 API 项目可使用的模型名称。若状态显示未配置，也在环境变量中设置它。
  4. 重新部署并检查环境变量修改后，需要重新部署一个已保存的站点版本才会生效。部署完成后回到本页点「重新检查」。
密钥轮换

需要替换或撤销时，在同一个原生设置里更新或移除该 Secret，再重新部署；旧密钥请在 OpenAI 平台撤销。
