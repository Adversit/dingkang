2026-09-28 查阅的在线 Tools reference 已描述某些新版本放宽“先读/文件变动”的条件；与本压缩包的严格校验片段不完全相同。本教学版按本轮讨论和附件快照保留严格先读、拒绝陈旧写入，不声称对应当前发布版的全部行为。
