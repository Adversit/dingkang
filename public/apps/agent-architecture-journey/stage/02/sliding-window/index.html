滑动窗口

保留最近消息时会失去什么

原稿 · Python 教学版0 段代码真实模型验证未提供

3. 最简单的方法：滑动窗口

一个很自然的方案是只保留最近几轮：

旧消息 1  ❌
旧消息 2  ❌
旧消息 3  ❌
……
最近消息 8 ✅
最近消息 9 ✅
最近消息 10 ✅

这样确实可以控制上下文长度。

但是问题也很明显：

  • 关键决策可能发生在很早以前；
  • 用户的重要约束可能被滑出窗口；
  • 早期读到的文件、错误原因、任务目标可能被一起删掉；
  • Tool Use 和 Tool Result 也不能随便从中间切开。

所以，单纯的 Sliding Window 太粗暴。

我更倾向于：不同类型的信息，用不同方式保留。
