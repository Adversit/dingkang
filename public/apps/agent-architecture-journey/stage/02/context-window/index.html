2. 上下文窗口是什么？

我目前把 Context Window 理解为：

模型一次调用能够使用的上下文容量。

它不是“无限记忆”，而是这一次模型推理时能看到多少东西的边界。

随着 Agent 不断运行，Context 中会不断加入：

用户消息
Assistant 消息
Tool Call
Tool Result
文件内容
系统提示
项目规则
环境信息
Memory
……

如果全部永久保留，很快就会遇到两个问题：

  1. 容量问题：最终会接近模型的上下文上限；
  2. 注意力问题：即使还没超限，把大量已经没价值的旧信息继续塞进去，也会让模型更难聚焦当前任务。

因此我觉得，真正的问题并不是：

怎么把所有信息都保存下来？

而是：

哪些过去的信息，在当前这一轮还值得让模型看到？

这也是我现在对 Context Management 的核心理解。
