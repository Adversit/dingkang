STAGE 02 / CHAPTER 01

为什么需要记忆

让前一步的结果在后续调用中继续可用

原稿 · Python 教学版0 段代码真实模型验证未提供

1. 为什么需要记忆？

如果只是单纯的一问一答，那么每次模型调用结束之后，下一次调用并不会天然知道上一轮发生了什么。

对 Agent 来说，这个问题更明显。比如刚刚已经：

Read app.py
→ 找到问题
→ Edit app.py
→ Bash 跑测试
→ 测试通过

如果这些结果没有被保留下来，下一轮模型可能又要重新 Read、重新判断、重新执行。

所以我目前理解，Agent 必须有某种机制，让之前发生过的事情在后续步骤中还能被继续使用。

最简单的方法，就是把之前所有消息全部保存，并在下一次调用时重新发给模型。

但问题也很明显：上下文不是无限的。
