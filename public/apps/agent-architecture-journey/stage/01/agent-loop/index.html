06 / 把工具接回 Agent

当前 Agent 只有一个明确循环：先给模型工具定义；模型返回 tool_use 后，程序按名称找到本地函数；把结果关联到原调用 ID，再作为下一轮消息发送。没有工具请求时，返回模型回答。L4

Agent 里保存客户端、模型名称、工具集合、system prompt 和步数上限。文件工具是 Python，沙箱由 Node 后端提供。“Agent 用 Python 写”不等于“必须把所有依赖都改写为 Python”。L1
