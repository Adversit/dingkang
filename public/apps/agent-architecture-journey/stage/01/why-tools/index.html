01 / 为什么需要工具

我曾经在 ChatGPT 里询问如何配置服务器的静态 IP。整个过程几乎都是：它给我命令，我去执行，再把结果贴回来，由它判断下一步。

在这条链路里，我承担了不少机械的执行和搬运工作。那么，能不能让 LLM 直接获得执行结果，并继续完成任务，而不必每一步都由我来中转？这就是我理解的“给聊天模型加上手”——工具。

但能执行和可靠地执行是两回事。Read 面对很大的日志文件，不能无限返回内容；Edit 修改文件前，需要考虑读完以后文件是否变过；Bash 能执行命令，也就需要限制命令能接触的资源。

这一阶段先围绕 Read、Write、Edit 和 Bash 展开。沙箱是 Bash 的执行后端，不是交给模型调用的第五个工具。L1

本轮只保留这条主线：模型提出操作 → 程序执行工具 → 返回结果 → 模型决定下一步。
