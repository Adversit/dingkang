03 / Read：读取指定范围的文本

我的起点

工具描述告诉 Agent：输入文件，返回文件内容。参数先考虑文件地址、offset 和 limit；输出要能区分正常文本和异常状态。

对普通文本，更准确地说是输入文件路径，读取并返回指定范围的内容。本学习版参数如下。L2 L3

参数 含义 本例约定
file_path 要读取的文件路径 必填；工作区内的绝对路径
offset 从第几行开始 可选，默认 1；从 1 开始计数
limit 最多返回多少行 可选；不是结束行号

例如 offset=10, limit=3 请求第 10～12 行，文件剩余不足三行时按实际内容返回。

内部先把文件字节按 UTF-8 解码为文本，再选择范围。输出中的文件名、实际范围和行号由程序拼接，属于结果格式化，不需要再次调用模型润色。空文件读取成功与文件不存在导致的失败，要分别表达。L3

范围和上限不是一回事

offset/limit 选择返回的行；大小上限判断本次读取和结果是否被允许。当前代码最多读取 1 MiB 的小文件，先有限量地整体读取，再按行选取；结果超过 32000 字节就报错，不静默截断。因此，不能用它证明已经实现了源码中的大文件流式读取。L3

PDF、音频和视频先保留为问题

你提出的“不同文件需要不同参数单位和内部逻辑”是后续方向。上传的 TypeScript Read 对 PDF 有独立的 pages 参数和文档/页面处理路径；这不等于把所有文件统一变成纯文本。Base64 是二进制数据的表示方式，不是对内容的文字转写。当前 Python Read 只支持 UTF-8 普通文本，不新增 PDF、图片、音频和视频能力。L1 L8
