STAGE 00 / FOUNDATION

Agent 的定义与最小循环

先把工具调用、反馈和再次判断连成一个可解释的闭环。

知识整理已完成伪代码尚未运行

四个来源，四个侧重点

来源中文概括
AnthropicLLM 动态决定执行过程和工具使用方式。
LangChain模型循环调用工具，直到任务完成。
OpenAI Agents SDKAgent 是配置了指令、工具和可选运行行为的 LLM。
Google ADKAgent 是为了实现特定目标而自主行动的执行单元。

以上为理解后的概括，不是逐字引文。

我的理解

Agent 就是在与 LLM 对话的基础上，可以调用外部工具，对外部环境产生反馈，并根据反馈进行规划，同时拥有记忆存储机制。

这是第一个 Agent 知识点。规划和记忆是逐步加入的目标；此处的最小循环只体现当前消息上下文与工具反馈。

最小 Agent Loop

模型每轮判断是否需要工具。工具结果写回消息上下文后，模型再次判断；无需工具时返回最终回答。

messages = [{"role": "user", "content": user_input}]

while True:
    response = call_llm(messages, tools=tools)
    messages.append(response)
    if not response.tool_calls:
        return response.content
    for tool_call in response.tool_calls:
        result = run_tool(tool_call.name, tool_call.arguments)
        messages.append({"role": "tool", "tool_call_id": tool_call.id,
                         "content": str(result)})

call_llm 和 run_tool 是抽象接口；这段代码说明控制流，没有经过运行验证。
