# 官方校园名称与资源复核（2026-10-25）

## 可确定的补充

新增独立 `public/apps/jlu-campus/data/official-name-overlay.json`。它保留全部地图ID、建筑轮廓、碰撞与传送点，仅提供有出处的名称/别名注释：南区5组新旧楼名对应，以及北区理化楼的近期官方名称确认。另列出6个官方资料出现但未可靠匹配OSM轮廓的北区名称，其坐标明确为空、导航禁用。

南区正式命名依据为吉林大学党委宣传部2021-12-03公告：
https://xcb.jlu.edu.cn/info/1009/1074.htm

北区近期依据为学校2026-04-08新闻，确认实地调研涉及理化楼、科技楼及原计算中心楼：
https://news.jlu.edu.cn/info/1021/60859.htm

鸣放宫可由学校新闻图集核验名称与前卫北区牡丹园归属；该图集为2005年的历史资料，不能单凭它确认2026年的使用状态：
https://news.jlu.edu.cn/info/1166/29450.htm

学校办公指南虽然仍可访问，但正文标明数据截止2019-06-05，不应作为现行部门入驻情况：
https://www.jlu.edu.cn/info/1240/45864.m.htm

## 官方公开接口核查

官方地图前端公开调用 `GET https://map.jlu.edu.cn/pois?term=名称` 进行搜索联想。本次按已知楼名进行少量无认证查询，理化楼、科技楼、鸣放宫、计算中心返回HTTP200；文科楼和设备楼未返回匹配。响应位置为官方画布坐标，未声明为WGS84。名称的存在不等于已解决这些点与OSM轮廓的对应关系。

未在已检查的主页、前端引用或2026-04-17平台上线公告中找到开放数据再分发许可。公开可浏览不能当作三维模型、矢量、贴图或整套POI数据库可复制的授权。本项目没有导出这些受权利约束的素材；研究用页面、脚本和查询响应仅留在临时分析目录，不进入发布资源。

## 北区仍有明确缺口

现有OSM边界内26栋建筑只有3个名称。新增证据层**没有猜测给其余23栋改名**。科技楼、原计算中心楼、鸣放宫等可确认名称，但缺少足够可靠的几何对应证据。游戏中的完整已标注校界范围，不等于现实楼宇、围墙、入口及用途全部核验完成。

如要求上述内容全部精确，应向吉林大学资产管理处数据资产管理科申请可公开复用的现行楼名—楼宇标识—位置对应表，以及出入口/通行限制；并同时确认坐标系、更新时间、衍生开发与再分发授权。2026-04-17上线通知公开联系方式为0431-85152166：
https://zcgl.jlu.edu.cn/info/1067/5881.htm

公开OSM和自制美术能够继续支持校园漫游开发。需要申请的是官方精确补齐资料，不能据此宣称整个工程已被强制阻塞，也不能将未核验部分宣称已完成。
