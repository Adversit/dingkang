# 灵感轨道：让动态贯穿工作空间

本轮将动态从首屏的一件轨道装置扩展到整个个人工作空间。背景、导航、分类、应用入口和数据中心处于同一个视觉环境中；标题、说明与点击位置保持稳定，方便长时间使用。

## 视觉方向

采用通透的冷白创作空间。桌面左侧以大字号呈现“让好奇心，自由运行”，右侧放置银蓝与淡紫交织的立体丝带。向下滚动时，形体退到页面边缘，内容逐步成为视觉主体。手机改为文字、形体、四个分类入口依次排列，应用列表使用单列。

| 色彩 | 色值 | 用途 |
|---|---|---|
| 冷白 | `#F1F4FA` | 全页基底 |
| 墨蓝 | `#1E2944` | 标题与主要文字 |
| 钴蓝 | `#3549C5` | 主要操作与当前选择 |
| 银蓝 | `#A4B3CF` | 形体、高光和细部轮廓 |
| 淡紫 | `#B8AFE8` | 丝带与背景反射 |
| 水青 | `#72D4CD` | 光场中的少量冷色变化 |

字体沿用本地 Manrope 与 Noto Sans SC。桌面主标题约 60–112px，窄屏约 49–78px；应用名 23–25px，正文 16–19px，辅助文字至少 14px。标题与正文左对齐，首屏保留完整留白；应用内容按研究、产品、生活、游戏组织，不增加无意义的编号或装饰性小字。

## 动态与操作的对应关系

| 区域 | 持续变化 | 用户操作后的反馈 |
|---|---|---|
| 全页背景 | 缓慢移动的光场与反射 | 滚动时形体移向页面边缘，降低透明度和尺寸 |
| 主视觉 | 实时丝带旋转与轻微形变 | 鼠标带来有限视角变化；窄屏保持稳定中心 |
| 主导航、分类和风格切换 | 无持续位移 | 当前选择的滑块按按钮实际位置和宽度移动 |
| 四个分类入口 | 细线轨道缓慢转动 | 悬停改变表面与箭头，点击进入共享分类 |
| 研究与产品应用 | 轨道或层叠图形分别运转 | 卡片轻微倾斜，局部光照跟随指针 |
| 生活与游戏应用 | 封面的缓慢反光 | 封面产生有限视差，保持文字可读 |
| 分类标题与页脚 | 页脚细线缓慢流动 | 分类标题进入视口时展开 |
| 数据中心 | 沿用全页背景 | 文件行、按钮、表单保留明确的悬停和焦点状态 |

应用名、说明和业务数据不做持续漂移。打开应用仍走主站的共享流程；进入模块时停止主站持续运动。游戏与业务页面本身沿用各自界面，本轮没有改写它们的内部功能。

## 实现与降级

`KineticBackdrop` 使用已有 Three.js 依赖绘制丝带几何、金属材质和程序生成的灯光环境。运行时不下载新的主视觉图片；生活与游戏封面继续使用仓库已有素材。WebGL 创建失败或上下文丢失时，CSS 形体承担主视觉，仍保留背景流动与滚动位置变化。

两种形体共用首屏位置、缩放、透明度和退到页面边缘的规则。首屏布局只在滚动、尺寸或视图变化后重新测量，避免每帧读取 DOM。`data-renderer="webgl"` 或 `"fallback"` 标记实际使用的绘制方式，便于检查，不能把降级截图当作完整 WebGL 材质的验收证据。

| 文件 | 职责 |
|---|---|
| `components/KineticScene.tsx` | 首屏文案、分类入口、最近使用与暂停按钮 |
| `components/KineticBackdrop.tsx` | 全页形体、灯光环境、滚动布局与资源释放 |
| `components/KineticBackdrop.module.css` | 光场与 CSS 降级形体 |
| `components/KineticMotion.tsx` | 将展示控制器挂到当前工作空间 |
| `lib/hub/kinetic-motion.ts` | 滚动、视口观察、卡片指针反馈与导航滑块测量 |
| `app/kinetic.css` | 整页排版、卡片样式、动效及响应式规则 |

这些组件不访问账号、业务 API 或存档。分类、启动应用、文件入口及外观偏好仍由 `app/page.tsx` 负责；目录继续读取 `lib/hub/catalog.ts`，没有新增主题专用存储格式或依赖。

## 性能与可用性

- 首屏的暂停按钮复用现有外观偏好；系统“减少动效”优先。页面隐藏或应用打开时停止持续绘制，恢复后按当前状态继续。
- WebGL 设备像素比上限为桌面 1.5、窄屏 1.25；窄屏约 30 FPS。场景不使用额外的后处理渲染链。
- 滚动与鼠标事件共用待执行的 RAF；展示控制器空闲时没有持续循环。屏幕外的入口动画暂停。
- 只有精细鼠标输入启用卡片倾斜；触摸、键盘焦点和离开卡片会复位。分类与应用仍由普通按钮操作。
- 内容默认可见，不依赖入场动画才能读到。关闭动效或不支持视口观察时，分类、搜索和应用入口保持可用。
- 卸载时取消 RAF、断开观察器和监听器，并释放几何、材质、环境纹理和渲染器；初始化中途失败也释放已创建的资源。

## 2026-10-24 验证范围

TypeScript 检查与 21 项相关测试通过，其中包含四种风格共享路由、保存与 iframe 保持的 15 项测试，以及指针边界、RAF 合并、隐藏暂停、减少动效、键盘／触摸复位、导航测量和清理的 6 项动效测试。构建助手返回成功；发布结果由本轮部署记录单独确认。

实际浏览器检查覆盖 1363 × 936 桌面页面，以及同源 iframe 中的 375 × 812、320 × 812、768 × 812 布局。检查中修复了 375px 风格按钮换行、320px 顶栏设置按钮被裁切的问题；后者修复后，最右控件位于 293px，处于 305px 的可用内容宽度内。目录跳转、暂停和恢复、产品分类筛选、星屿搜索、打开模块后停止动效，以及模块内切换风格后保留 iframe 地址均已实际操作。

预览环境未登录，返回模块时触发既有保存连接错误并保留了当前模块，因此本轮不宣称通过完整的登录、云存档与返回流程浏览器验收；保存失败保护与共享路由另由相关单元测试覆盖。

测试浏览器报告 `GL_VENDOR = Disabled`，因此页面实测及 README 截图使用 **CSS 轻量动态版本**。完整 WebGL 材质效果、真实 GPU 帧率以及实体手机的触摸与耗电情况尚未验证；嵌入式窄屏检查也不能替代真机验收。此前暖居场景的待复核项保持原记录，不因本轮动态主题检查而视为完成。
