# 暖居海岛验证记录

本轮将粗几何场景替换为精细环境美术与局部 WebGL 动态。场景为固定视角 2.5D，提供有限视差、横向观察和房间过渡。

## 已验证

- 共享存储、身份隔离、备份导入、离开保护与主题导航测试通过；本轮没有改变业务 API 或存档格式。
- 15 个物件的实际多边形通过 Three.js 射线命中测试，覆盖桌面、375px 与 320px 视口。测试保留真实相机和拾取几何，GPU 与图片 I/O 使用替身。
- 建筑先选中再确认进入；过渡期间防误触；异步贴图不会覆盖后来选择的房间；隐藏页面、减少动效和释放资源有回归测试。
- 环境音默认关闭，主动开启、后台停声、卸载清理和异步开启竞态有测试覆盖。
- 在线桌面实测：研习书屋的星象仪打开知流；造物工坊的画架打开 AI PM Studio；日常小屋的落地灯打开晚灯；冒险收藏室的邮船打开雾海来信。返回应用入口时保留原房间。
- 四间室内的实际渲染画面已查看；海岛实际页面截图保存在 `docs/screenshots/cozy.webp`。
- 资源包 20 项测试通过；空目录离线还原全部 15 个资源路径并逐项验证 SHA-256，再次还原正确跳过 15 个路径。两款游戏共用的战斗音频引用同一套分片，仓库共保存 14 份不同资源、51 个分片。

## 本轮实测后的修正

- 宽屏边缘使用同一场景的柔焦底图，保留主画面的完整构图。
- 修正桌面导航贴边；场景与底图层使用 `overflow: clip`，避免聚焦控件时画面内部发生意外滚动。
- 为手机上的图标按钮保留独立的可访问名称，隐藏文字后仍能识别“房间物件”和“目录”。
- 在 320px 等窄屏中将室内标题和工具栏分为两行，物件清单相应下移；图标按钮保持至少 44px 的触控目标。

## 尚待完整复核

浏览器验证在手机检查期间中断。最终 CSS 修正后的手机截图、完整触摸流程和环境音实际听感尚未完成复核；自动化测试不替代这些检查。后续应重点检查 320px / 375px 的标题、工具栏与物件清单遮挡，以及场景平移后各物件的实际可达性。

README 的室内展示使用已生成并在游戏中应用的环境美术，明确标注素材性质；不将环境素材当成运行中的界面截图。
